# Capstone 1 – Version 2.0

## Project Overview

This project enhances an original Capstone 1 sales analysis by transforming SQL and Excel findings into an interactive Power BI dashboard. The dashboard allows users to explore sales performance, monthly revenue trends, product-category results, territory and regional comparisons, and store rankings.

The goal of Version 2.0 is to make the original analysis more interactive, visually engaging, and easier for the audience to understand. The project also includes updated insights and recommendations based on the Power BI visualizations.
